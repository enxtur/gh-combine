gh-combine
Install Usage Notes GitHub

Combine several pull requests into one

A GitHub CLI extension that cherry-picks the commits from each PR onto a fresh branch, pushes it, and opens a combined PR that links back to the originals.

Get started View on GitHub 
$ gh combine 12 34 56

Switched to a new branch 'combine-prs-12-34-56'
[combine-prs-12-34-56 a1b2c3d] Add retry to the fetch client
[combine-prs-12-34-56 e4f5a6b] Bump actions/checkout from 6 to 7
[combine-prs-12-34-56 c7d8e9f] Document the cache headers
To github.com:you/your-repo.git

Created PR: https://github.com/you/your-repo/pull/57

Installation

Requires the GitHub CLI.

gh extension install enxtur/gh-combine

Usage

Run from a clone of the repository the PRs belong to:

gh combine 12 34 56

Each argument is anything gh pr view accepts — a PR number, URL, or branch name.

What it does

  1. Creates the branch

    Branches combine-prs-12-34-56 off main, from scratch each run.

  2. Replays the commits

    Cherry-picks the commits of #12, #34, and #56 onto it, in the order you listed them.

  3. Pushes and opens the PR

    Force-pushes the branch to origin and opens a PR titled Combine #12, #34, #56, with the original PRs listed in the body.

Notes

  • The base branch is main.
  • The head branch is force-pushed, and re-running the same command recreates it from scratch — so you can rerun after a PR is updated.
  • If a cherry-pick conflicts, the run aborts it and exits with the error. Resolve the conflict in the source PR and try again.

Development

go build
gh extension install .

Releases are built by cli/gh-extension-precompile when a v* tag is pushed.
